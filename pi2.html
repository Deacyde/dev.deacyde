Pi2 SSH Setup for Star

Tap any copy button to grab the command, paste it into Pi2's terminal. Run steps in order.

Before you start Pi2 needs to be on the network and have a terminal open (keyboard + screen, or existing access). HTTPS hosting here makes clipboard copy more reliable than local HTTP pages.
1
Enable SSH on Pi2

Installs and starts the SSH server. Safe to run even if SSH is already installed.

bash 
sudo apt update
sudo apt install -y openssh-server
sudo systemctl enable --now ssh
sudo systemctl status ssh --no-pager
2
Add Star's SSH key

Adds the Star VM public key to authorized_keys so Star can connect without a password.

bash 
mkdir -p "$HOME/.ssh"
chmod 700 "$HOME/.ssh"
printf '%s\n' 'ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIMBT9wijjeRu6j5SCZ2bkT1J7+gHiwhq9zlYmoLeibDQ openclaw3@star-vm' >> "$HOME/.ssh/authorized_keys"
chmod 600 "$HOME/.ssh/authorized_keys"
grep -n 'openclaw3@star-vm' "$HOME/.ssh/authorized_keys"
3
Report Pi2 identity back

Run this and send the output — USER, HOSTNAME, and IPs — back so Star knows how to reach Pi2.

bash 
echo "USER=$(whoami)"
echo "HOSTNAME=$(hostname)"
echo "IPS=$(hostname -I)"
ip -br addr show | grep -E 'wlan0|eth0'
Optional steps
A
Set hostname to pi2

Only needed if the hostname is wrong. Reboots the machine.

bash 
sudo hostnamectl set-hostname pi2
sudo reboot
B
Quick auth self-check

Confirms the key was written correctly.

bash 
ls -ld "$HOME/.ssh"
ls -l "$HOME/.ssh/authorized_keys"
tail -n 5 "$HOME/.ssh/authorized_keys"
